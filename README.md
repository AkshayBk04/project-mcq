# PROJECT MCQ v1.6

**UGC NET Adult Education: Previous-Year Questions (2012–2023)** adds **2,175 questions from all 19 sessions in the supplied book**. This full-site package preserves all six v1.5 banks: **4,799 questions in total**.

Each Adult Education record includes four choices, an explanation and its examination session/year at the end. Papers II and III retain their numbering. Passages and original images preserve tables, codes and mathematical symbols. Some answer buttons refer to the choices in the image above them.

Coverage refers to the supplied book, not every examination ever held in 2012–2023. Both 2019 sessions and the separately supplied June 2020 paper are included.

## Answer and transcription notes

Explanations are editorial study notes. Damaged wording has been reconstructed where necessary and is labelled. Original PDFs/images are included for comparison. This is not a certification against a complete official final-answer-key set.

**375 items are retained but excluded from scoring** because of ambiguous wording, cancelled questions, questionable keys or unresolved source issues. Printed/provisional keys are shown where available. Unknown answers are not replaced with option A. Identified corrections are explained; multiple accepted answers are supported.

`ADULT_EDUCATION_REVIEW_NOTES.md` lists these items. `data/adult-education-pyqs.json` is the reusable export; the matching `.js` loads the bank into the site.

## Upload to GitHub Pages

1. Extract the ZIP.
2. Upload its **contents** to the root of the existing `project-mcq` repository, preserving the `data/` and `assets/` folders and replacing matching files. Upload the extracted files, not the ZIP itself.
3. Commit and let the existing GitHub Pages deployment finish. Keep the current Pages settings.
4. Refresh the site. It should show seven banks and 4,799 questions. Choose Adult Education and select a session/paper.

GitHub Desktop or git is convenient for uploading the large number of source images. Every file is below 25 MiB. June 2019's reference PDF is split into two parts, with links adjusted to the correct page.

No backend, build step or API key is required. Progress is stored in the browser's local storage.
